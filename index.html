Module Core Purpose

This module does not teach a specific programming language[cite: 3]. Instead, it teaches the foundational problem-solving and algorithmic logic skills needed to learn and program in any programming language[cite: 3].

Key Principles

  • Programming Defined: Writing detailed instructions for a computer to carry out specific tasks[cite: 4].

  • Progression Path: Commitment, daily practice, repetition, curiosity, and research[cite: 24].

Software Development Life Cycle (SDLC)

Software development follows a cyclical sequence of six key stages[cite: 5]:

  1. Planning: Plan the overall project scope[cite: 5].
  2. Analysis: Define requirements and specifications[cite: 5].
  3. Design: Design the system architecture[cite: 5].
  4. Implementation: Code and build software modules[cite: 5].
  5. Testing & Integration: Evaluate and merge code[cite: 5].
  6. Maintain: Fix bugs and implement updates[cite: 5].

Categories of Software

  • Systems Software: Drives hardware (e.g., Windows, macOS, Linux)[cite: 6].
  • Application Software: Performs user tasks (e.g., Office, Minecraft, Email)[cite: 6].
  • Software Tools: Languages to build software (e.g., Python, C++, Java)[cite: 6].

Solution to Program Pipeline

Express natural language solutions as algorithms before writing code[cite: 28]:

  • Algorithm: A finite, structured set of step-by-step instructions[cite: 29].
  • Computer Models: Simplified representations to simulate systems safely[cite: 30].
  • Generalisability: Algorithms solve all variations of a given problem[cite: 31].

Abstraction & Optimisation

  • Abstraction: Removing unnecessary lower-level detail[cite: 32]. Uses Hierarchical Task Analysis (HTA) or Top-Down Refinement[cite: 33].
  • Optimal Algorithm:
    1. Uses minimum execution steps[cite: 35].
    2. Avoids errors under unforeseen conditions[cite: 35].
    3. Features modular components designed for reusability[cite: 35].

3 Basic Constructs

Any computational problem can be solved using these three constructs[cite: 36]:

1Sequence
The precise logical order in which steps are executed[cite: 37, 51].
2Selection
Branching execution paths based on logical conditions (IF/ELSE)[cite: 37].
3Iteration
Repeating steps until a condition is met (FOR/WHILE loops)[cite: 37].

Pseudocode Standards (Gaddis Style)

  • Each statement is numbered on its own line ending with `;`[cite: 48].
  • Begins with PROGRAM <Title> and ends with END[cite: 48].
  • Keywords are written in UPPERCASE[cite: 48].
PROGRAM <SnackVending>
1. Process payment;
2. Make selection;
3. Dispense snack;
4. Return change;
END

Pros & Cons of Pseudocode

Advantages
  • Language independent; easy to read[cite: 49].
  • Focuses strictly on logic[cite: 49].
Disadvantages
  • Time-consuming to update manually[cite: 50].
  • Cannot be directly executed on a computer[cite: 50].

Input-Processing-Output (IPO) Model

Algorithms process input data to transform it into meaningful information output[cite: 56]:

  • Input Sources: Keyboard/mouse (manual), files/databases (stored), or sensors[cite: 78].
  • Processing: Data manipulation, logic execution, and mathematical operations[cite: 57].
  • Output Destinations: Screen displays, terminal outputs, or text/database files[cite: 79].

Variables & Memory Allocation

A variable is a named location in RAM memory used to store and update data during runtime[cite: 63].

  • Declaration: Declares variable name and data type using DECLARE (e.g. DECLARE String name;)[cite: 64].
  • Initialization / Assignment: Assigning an initial value with SET (e.g. SET name = "Ian";)[cite: 69].
  • Variable States:
    • Undefined: Not declared yet[cite: 72].
    • Null / Uninitialized: Declared, but no value assigned[cite: 72].
    • Empty: Set to "" or 0[cite: 72].
    • Assigned: Holds a valid non-null value[cite: 72].

Naming Rules & camelCase

  • Must start with a letter and contain no spaces or special punctuation[cite: 67, 68].
  • Cannot use reserved programming keywords or language identifiers[cite: 68].
  • camelCase Standard: First word lowercase, subsequent words capitalized (e.g. personCount)[cite: 67].
  • Constants: Values that remain fixed throughout execution (e.g. SET PI = 3.142;)[cite: 70].

Math & String Operators

  • Concatenation (&): Joins strings together (e.g. "Mr " & name)[cite: 75].
  • Arithmetic Operators: +, -, *, /, ^[cite: 74].
  • Modulo (%): Returns integer remainder of division (e.g. 5 % 2 evaluates to 1)[cite: 77].
  • Floor / Integer Division: Uses int(5 / 2) to extract only the quotient (2)[cite: 77].

Operator Precedence (BODMAS)

  1. Brackets[cite: 76]
  2. Order / Exponents[cite: 76]
  3. Division & Multiplication[cite: 76]
  4. Addition & Subtraction[cite: 76]

Operators of equal precedence evaluate from left to right[cite: 76].

Keyboard vs. Stored File I/O

Pseudocode syntax for manual input and file handling[cite: 80, 81]:

Keyboard I/O Example:

PROGRAM
DECLARE String firstName;
OUTPUT "Enter your name";
INPUT firstName;
OUTPUT "Hello " & firstName;
END

File READ / WRITE Example:

PROGRAM
DECLARE String name;
OPEN "name.txt" mode read;
READ name;
CLOSE;

OPEN "output.txt" mode write;
WRITE "Mr " & name;
CLOSE;
END
