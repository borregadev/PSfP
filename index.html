Session 1: Programming & Problem Solving

Core concepts, Software Development Life Cycle (SDLC), and the HTTLAP problem-solving framework.

Software Development Life Cycle (SDLC)

Software development follows a structured, cyclical lifecycle divided into six critical sequential stages:

Systems Software:

Directly controls hardware resources (e.g., Windows, macOS, Linux).

Application Software:

Performs user-defined tasks (e.g., Browsers, Office Suites, Games).

Software Tools:

Languages and tools used to construct software (e.g., Python, C++, Java).

HTTLAP Framework (Paul Vickers)

Structured methodology for problem-solving from How to THINK Like a Programmer:

U Understand

Determine problem type, remove ambiguity, identify knowns/unknowns.

P Plan

Represent graphically or numerically; identify underlying patterns.

S Solve

Structure logic observing Sequence, Selection, and Iteration constructs.

A Assess

Verify logic thoroughly using distinct sets of input test data.

R Reflect

Maintain a learning journal; identify generalization possibilities.

D Document

Explain logic clearly so future engineers can maintain and update code.

Essential Problem-Solving Techniques

Visual Representation

Tables, diagrams, and flowcharts reduce cognitive load and structure relationships.

Simpler Analogous Task

Solve a scaled-down version first with fewer variables and minimal data points.

Pattern Identification

Uncover mathematical or logical repetitions to establish re-usable functions.

Intelligent Guessing

Eliminate impossible options systematically to increase guess accuracy.

3 Fundamental Constructs

1. Sequence

The exact logical order in which statements and instructions execute sequentially line-by-line.

2. Selection

Branching logic where paths are selected dynamically based on evaluating condition expressions (e.g., IF / ELSE).

3. Iteration

Repeating a sequence block until a specific logical condition is satisfied (e.g., FOR, WHILE loops).

Gaddis Pseudocode Conventions

// Gaddis Standard Pseudocode Example

PROGRAM SnackVending

1. OUTPUT "Process payment";

2. OUTPUT "Make selection";

3. OUTPUT "Dispense snack";

4. OUTPUT "Return change";

END

Key Pseudocode Guidelines:

  • Enclosed using PROGRAM <Name> and END keywords.
  • Keywords are strictly UPPERCASE (DECLARE, SET, INPUT, OUTPUT).
  • Each statement occupies its own line ending with a semicolon (;).
  • Sequential statement lines are numbered explicitly.

Variables & RAM Memory Concept

A variable represents a named location in RAM memory created during runtime to store data values that may change during program execution.

Camel Case Rule: Multi-word variables use camelCase (e.g., personCount).

Declaration Syntax: DECLARE String carRegistration;

Variable States & Operators

Undefined

Not declared in code scope.

Null / Uninitialized

Declared, no value assigned.

Empty

Set to "" or 0.

Assigned

Holds valid non-null data.

Special Mathematical Operators:

  • Concatenation (&): Joins strings together ("Mr " & name).
  • Modulo (%): Returns the integer remainder of division (5 % 2 = 1).
  • Floor Division: Calculates the integer quotient (int(5 / 2) = 2).

Complete Algorithm Example (Keyboard & File I/O) 

PROGRAM SheepAndChickens
    DECLARE Integer sheep, chickens, legs, animals;
    DECLARE String result;

    // Manual Keyboard Input
    OUTPUT "Enter number of legs:";
    INPUT legs;
    OUTPUT "Enter number of animals:";
    INPUT animals;

    // Calculations
    SET sheep = (legs - animals * 2) / 2;
    SET chickens = animals - sheep;
    SET result = "Sheep=" & sheep & " Chickens=" & chickens;

    // Output & File Handling
    OUTPUT result;
    OPEN "results.txt" mode write;
    WRITE result;
    CLOSE;
END
